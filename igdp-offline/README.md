# igdp-offline 离线数据同步模块

## 模块说明

`igdp-offline` 模块专门用于处理移动端（smartag-app）离线数据的同步请求。当移动端在离线模式下填写完数据后，会在网络恢复时通过此模块将数据同步到后端数据库。

## 功能特性

1. **统一同步接口**：提供统一的离线数据同步接口，处理不同业务模块的同步请求
2. **数据校验**：参考PC端校验规则，对同步的数据进行严格校验
3. **业务解耦**：通过调用各业务模块的Service，实现数据同步与业务逻辑的解耦

## 接口说明

### 1. 同步农民数据

**接口地址**：`POST /offline/sync/farmer`

**请求体格式**：
```json
{
  "businessType": "farmer",
  "formCode": "farmer-add",
  "formData": {
    "farmerName": "农民姓名",
    "idCard": "身份证号",
    "gender": "MALE",
    "phone": "手机号",
    ...
  },
  "clientRecordId": "客户端记录ID"
}
```

**校验规则**：
- 农民姓名：必填，最多100个字符
- 身份证号：必填，最多50个字符，需唯一
- 电话号码：可选，格式校验（只允许数字、+、-、空格）

### 2. 同步土地数据

**接口地址**：`POST /offline/sync/land`

**请求体格式**：
```json
{
  "businessType": "land",
  "formCode": "land-add",
  "formData": {
    "landName": "地块名称",
    "ownerType": "PRIVATE",
    "landType": "DRY",
    "areaSize": 10.5,
    "kebeleCode": "村代码",
    "address": "详细地址",
    ...
  },
  "clientRecordId": "客户端记录ID"
}
```

**校验规则**：
- 地块名称：必填，最多100个字符
- 土地权属：必填
- 地块类型：必填
- 地块面积：必填，必须大于0
- 村代码：必填
- 详细地址：必填

## 模块依赖

- `igdp-common`：通用工具类
- `igdp-farmland`：农田管理模块（用于调用农民和土地服务）

## 使用说明

1. 移动端在离线模式下填写表单数据
2. 数据保存在本地存储中
3. 网络恢复后，点击"立即同步"按钮
4. 系统自动调用对应的同步接口
5. 后端进行数据校验和保存
6. 返回同步结果

## 注意事项

1. 数据校验规则与PC端保持一致，确保数据一致性
2. 身份证号唯一性校验，防止重复数据
3. 所有必填字段必须提供，否则同步失败
4. 同步失败的数据会保留在本地，可重试同步
