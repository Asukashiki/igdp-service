# API封装规范

API统一使用：

```javascript
import agricultureRequest, { toCamelCase, toSnakeCase } from '../utils/agricultureRequest'
```

示例：

```javascript
export const getInventoryList = (params = {}) => {
  const requestParams = {
    page: params.page || 1,
    pageSize: params.pageSize || 10
  }

  if (params.warehouseId) requestParams.warehouseId = params.warehouseId
  if (params.inputId) requestParams.inputId = params.inputId
  if (params.batchNo) requestParams.batchNo = params.batchNo
  if (params.stockStatus !== undefined && params.stockStatus !== null && params.stockStatus !== '') {
    requestParams.stockStatus = params.stockStatus
  }

  return agricultureRequest({
    url: '/inventory/stock/query',
    method: 'get',
    params: requestParams
  }).then(res => {
    if (res.data && res.data.list) {
      res.data.list = res.data.list.map(item => toSnakeCase(item))
    }
    return res
  })
}
```

要求：

1 所有API统一写在

```
src/api/inventory.js
```

2 字段统一使用 snake_case

3 API返回结构：

```
{
 code:200,
 data:{
  list:[],
  total:100
 }
}
```

操作：新增、查看、编辑、删除、审批
按钮权限的描述:
1.查看所有状态下都能显示
2.编辑按钮在待审批状态下显示,其余状态不显示
3.删除按钮在待审批状态下显示,其余状态不显示
4.审批按钮在待审批状态下显示,其余状态不显示

#### 入库申请场景:
```
1.入库申请,在index页面点击按钮"入库申请"或者"add"按钮,进入form页面,新增页面
2.填写入库基本信息和入库商品明细子表然后点击提交
3.提交成功改变当前单子的状态为(待审批)
4.如果满足则index页面出现一条待审批的申请单
5.审批人员审批状态为待审批的申请单,然后点击审批按钮,弹出需要填写的意见框下面有两个按钮"同意"和"不同意"
6.点击"同意",提交到后端,并且触发入库的逻辑,修改单子状态(已完成)
7.如果点击"不同意"则保存意见,不进行入库操作,修改单子状态(未通过)
8.detail页面需要添加审批意见的显示
```
