# 页面详细设计

## 1. index.vue 页面

### 搜索区字段：
1. 调拨类型 - 下拉框 (STOCK_WARNING:库存预警, FULL_TRANSFER:满仓调离)
2. 调拨申请日期 - 日期范围选择器 (开始日期 - 结束日期)

4. 调入仓库 - 下拉框选择

| transfer_type | 调拨类型 |

| out_warehouse_name | 调出仓库 |
| out_time | 调出时间 |
| applicant | 提交人 |
| in_warehouse_name | 调入仓库 |
| in_time | 调入时间 |

- 待审批 (SUBMITTED)

# 业务场景流程

```
1. 调拨申请,在index页面点击按钮"调拨申请"或者"add"按钮,进入form页面,新增页面
2. 填写调拨基本信息和调拨商品明细子表然后点击提交
3. 提交成功改变当前单子的状态为(待审批)
4. 如果满足则index页面出现一条待审批的申请单
5. 审批人员审批状态为待审批的申请单,然后点击审批按钮,弹出需要填写的意见框下面有两个按钮"同意"和"不同意"
6. 点击"同意",提交到后端,并且触发调拨的逻辑,修改单子状态(已完成)
7. 如果点击"不同意"则保存意见,不进行调拨操作,修改单子状态(未通过)
8. 在同意后触发出库和入库的逻辑操作,并且创建一条入库单和出库单,自动填写里面所有的信息包含子表信息,并且将单子状态改为已完成
9. detail页面需要添加审批意见,审批人和审批时间的显示
```

# API 代码

```javascript
// api/inventory.js - Transfer APIs

// Get transfer list
export const getTransferList = (params = {}) => {
  const requestParams = {
    page: params.page || 1,
    pageSize: params.pageSize || 10
  }

  if (params.transferType) requestParams.transferType = params.transferType
  if (params.startDate) requestParams.startDate = params.startDate
  if (params.endDate) requestParams.endDate = params.endDate
  if (params.outWarehouseId) requestParams.outWarehouseId = params.outWarehouseId
  if (params.inWarehouseId) requestParams.inWarehouseId = params.inWarehouseId
  if (params.status) requestParams.status = params.status

  return agricultureRequest({
    url: '/inventory/transfer/list',
    method: 'get',
    params: requestParams
  })
}

// Get transfer detail
export const getTransferDetail = (id) => {
  return agricultureRequest({
    url: `/inventory/transfer/${id}`,
    method: 'get'
  })
}

// Create transfer
export const createTransfer = (data) => {
  return agricultureRequest({
    url: '/inventory/transfer/create',
    method: 'post',
    data: toSnakeCase(data)
  })
}

// Update transfer
export const updateTransfer = (data) => {
  return agricultureRequest({
    url: '/inventory/transfer',
    method: 'put',
    data: toSnakeCase(data)
  })
}

// Delete transfer
export const deleteTransfer = (id) => {
  return agricultureRequest({
    url: `/inventory/transfer/${id}`,
    method: 'delete'
  })
}

// Submit transfer
export const submitTransfer = (id) => {
  return agricultureRequest({
    url: '/inventory/transfer/submit',
    method: 'post',
    data: { id }
  })
}

// Audit transfer
export const auditTransfer = (id, approved, auditComment) => {
  return agricultureRequest({
    url: '/inventory/transfer/audit',
    method: 'post',
    data: { id, approved, auditComment }
  })
}
```
