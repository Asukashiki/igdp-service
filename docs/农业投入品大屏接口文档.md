# 农业投入品供应管理系统 - 大屏展示接口文档

## 概述

本文档描述了农业投入品供应管理系统大屏展示模块的所有API接口，包括请求参数、响应数据格式及示例。

**基础路径**: `/dashboard`

**通用响应格式**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { /* 具体数据 */ }
}
```

---

## 接口列表

### 1. 获取总览数据

#### 接口信息
- **URL**: `/dashboard/overview`
- **Method**: `GET`
- **描述**: 获取大屏总览数据，包括供应商、投入品、仓库、库存等核心指标

#### 请求参数
无

#### 响应数据

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "totalSuppliers": 150,
    "certifiedSuppliers": 120,
    "pendingSuppliers": 20,
    "rejectedSuppliers": 10,
    "totalInputs": 500,
    "seedInputs": 200,
    "fertilizerInputs": 180,
    "pesticideInputs": 120,
    "totalWarehouses": 15,
    "totalCapacity": 100000.00,
    "usedCapacity": 75000.00,
    "capacityUsageRate": 75.00,
    "totalStockQuantity": 75000,
    "normalStockCount": 450,
    "nearExpiryStockCount": 35,
    "expiredStockCount": 15,
    "todayStockInCount": 25,
    "todayStockOutCount": 18,
    "monthStockInQuantity": 5000,
    "monthStockOutQuantity": 4200,
```

#### 字段说明

| 字段名 | 类型 | 说明 |

### 2. 获取供应商TOP榜单

### 4. 获取入库出库趋势

#### 字段说明

| 字段名 | 类型 | 说明 |

## 使用示例

### JavaScript/Axios示例

```javascript
// 获取总览数据
axios.get('/dashboard/overview')
  .then(response => {
    const overviewData = response.data.data;
    console.log('供应商总数:', overviewData.totalSuppliers);
    console.log('库存使用率:', overviewData.capacityUsageRate + '%');
  })
  .catch(error => {
    console.error('请求失败:', error);
  });

// 获取供应商TOP10
axios.get('/dashboard/top-suppliers', {
  params: { limit: 10 }
})
  .then(response => {
    const suppliers = response.data.data;
    suppliers.forEach(supplier => {
      console.log(`${supplier.orgName}: 本月入库${supplier.monthStockInQuantity}件`);
    });
  });

// 获取7天趋势
axios.get('/dashboard/stock-trend', {
  params: { days: 7 }
})
  .then(response => {
    const trendData = response.data.data;
    // 用于图表展示
    const dates = trendData.map(item => item.date);
    const stockIn = trendData.map(item => item.stockInQuantity);
    const stockOut = trendData.map(item => item.stockOutQuantity);
  });

// 获取预警信息
axios.get('/dashboard/warnings', {
  params: { limit: 20 }
})
  .then(response => {
    const warnings = response.data.data;
    const highLevelWarnings = warnings.filter(w => w.warningLevel === 3);
    console.log('高级别预警数量:', highLevelWarnings.length);
  });
```

## 性能优化建议

### 大屏刷新策略

1. **总览数据**: 建议每30秒刷新一次
2. **TOP榜单**: 建议每1分钟刷新一次
3. **趋势图表**: 建议每5分钟刷新一次
4. **预警信息**: 建议每15秒刷新一次

### 缓存建议

对于实时性要求不高的数据，可以在前端进行缓存：

```javascript
// 使用localStorage缓存数据
const CACHE_TIME = 60000; // 1分钟

function getCachedData(key, fetchFunction) {
  const cached = localStorage.getItem(key);
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < CACHE_TIME) {
      return Promise.resolve(data);
    }
  }

  return fetchFunction().then(data => {
    localStorage.setItem(key, JSON.stringify({
      data: data,
      timestamp: Date.now()
    }));
    return data;
  });
}

// 使用示例
getCachedData('overview', () =>
  axios.get('/dashboard/overview').then(res => res.data.data)
).then(data => {
  // 使用数据
});
```

## 注意事项

1. **时区问题**: 所有时间字段均使用服务器本地时区
2. **数值精度**: 金额和容量类字段使用BigDecimal类型，保留两位小数
3. **空值处理**: 对于可能为空的统计数据，后端返回0而非null
4. **分页**: 目前TOP榜单和预警列表通过limit参数限制返回数量，不支持分页
5. **权限**: 所有接口需要登录后访问，未登录返回401错误
