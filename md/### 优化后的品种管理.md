# 1. 项目基础信息
## 1.1 开发背景
本模块为奥罗米亚州种子监管系统核心子模块，基于RuoYi平台二次开发，实现种子品种的标准化登记、合规性审核、公开化发布，需依赖「种子企业认证模块」（企业完成备案后方可操作）。
## 1.2 核心使用对象
- 种子企业人员：提交品种登记申请
- 审核人员：审核品种登记申请
- 管理人员：发布审核通过的品种信息

---

# 2. 品种登记功能
## 2.1 功能描述
种子企业完成备案后，通过该功能录入种子品种的基础信息、技术数据、证明材料，生成标准化品种登记档案，为后续审核、发布提供数据支撑。
## 2.2 操作流程
1. 企业人员点击「品种登记」按钮，弹出登记申请表单；
2. 填写表单并上传证明文件（PDF/JPG，单份≤2MB），支持「保存表单（暂存）」「提交申请（正式提交）」；
3. 提交后跳转至申请单列表页，列表支持以下查询条件：
   - 文本输入框：搜索品种名称；
   - 文本输入框：搜索企业名称；
   - 下拉框1：按企业类型筛选；
   - 下拉框2：按备案类型筛选。

## 2.3 业务逻辑
1. **前置条件**：操作企业必须已完成「种子企业认证备案」（`enterprise_info.certification_status = 1`）；
2. 企业按作物类型填写品种信息并上传材料，提交后系统生成**唯一登记申请号**，申请状态更新为「审核中（0）」；
3. 文件校验：仅支持PDF/JPG格式，单份文件大小≤2MB，格式/大小不符则提示错误；
4. 表单校验：必填字段（品种名称、作物类型、试验地点等）不能为空，格式错误（如日期、数值）实时提示。

# 3. 品种审核功能
## 3.1 功能描述
审核人员对企业提交的品种登记申请进行合规性审核，核验材料完整性、数据真实性后，通过「同意/驳回」操作给出审核结果，更新申请单状态。
## 3.2 操作流程
1. 审核人员进入「待办列表」，列表展示所有状态为“审核中（0）”的申请单；
2. 点击申请单进入详情页，选择「同意/驳回」并填写审核意见，点击「审核」按钮；
3. 审核完成后，系统更新登记申请单状态（通过→待发布/驳回→审核未通过），并生成审核记录。

### 3.2.1 待办列表查询条件
- 文本输入框：筛选品种名称；
- 文本输入框：筛选提交单位（企业名称）；
- 下拉框：按审核状态筛选。

## 3.3 业务逻辑
1. 审核前置条件：申请单状态为「审核中（0）」；
2. 审核通过：更新`variety_registration.record_status = 1`（待发布）；
3. 审核驳回：更新`variety_registration.record_status = 2`（审核未通过），且必须填写驳回原因；
4. 审核记录需关联登记申请ID，永久存档，支持追溯。

# 4. 品种发布功能
## 4.1 功能描述
管理人员将审核通过（状态为「待发布」）的品种信息录入公示数据库，通过平台向社会公示，实现品种信息可查询、可追溯。
## 4.2 操作流程
1. 管理人员进入「发布列表」，列表展示所有状态为「待发布（1）」的品种；
2. 操作列支持「预览发布信息」「立即发布」，点击「立即发布」需录入决策说明；
3. 发布完成后，品种状态更新为「已发布（1）」，同步至平台公示栏目。

### 4.2.1 发布列表查询条件
- 文本输入框：筛选品种名称；
- 下拉框：按作物类型筛选。

## 4.3 业务逻辑
1. 发布前置条件：品种登记申请状态为「待发布（1）」；
2. 发布后生成唯一「发布编号」，更新`variety_registration.record_status = 3`（已发布）；
3. 发布信息包含公示描述、推荐地区、播种指南等，支持公众查询；
4. 发布记录永久存档，支持下架操作（状态更新为「已下架（2）」）。
