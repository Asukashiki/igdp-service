# 农田管理系统后端开发提示词

## 1. 农民管理模块

### 1.1 农民认证申请功能

#### 接口设计
```restful
POST /api/farmer/certification/apply
GET /api/farmer/certification/status/{userId}
```

#### 开发要点
- 实现农民认证申请表单提交接口
- 身份证号格式验证（18位，包含校验码）
- 手机号码格式验证
- 文件上传功能（土地承包经营权证等证明材料）
- 申请状态实时查询
- 自动生成申请记录，初始状态设为"审核中"

#### 数据库操作
```sql
-- 插入认证申请记录
INSERT INTO farmer_certification (USER_ID, REAL_NAME, ID_CARD, AD_CODE, FARM_TYPE, CERT_DOC_PATH, DETAIL_ADDRESS, APPLY_TIME, STATUS) 
VALUES (?, ?, ?, ?, ?, ?, ?, NOW(), 1);

-- 查询认证状态
SELECT STATUS, APPROVE_TIME, REJECT_REASON FROM farmer_certification WHERE USER_ID = ?;
```

### 1.2 农民认证审批功能

#### 接口设计
```restful
GET /api/admin/certification/pending   # 获取待审批列表
GET /api/admin/certification/detail/{certId}  # 获取申请详情
POST /api/admin/certification/approve  # 审批通过
POST /api/admin/certification/reject   # 审批驳回
```

#### 开发要点
- 管理员身份验证和权限控制
- 待办事项列表分页查询
- 申请资料完整展示（包括文件预览）
- 审批操作记录（审批人、审批时间）
- 驳回原因必填验证
- 状态更新和用户通知

#### 数据库操作
```sql
-- 获取待审批列表
SELECT * FROM farmer_certification WHERE STATUS = 1 ORDER BY APPLY_TIME DESC;

-- 审批通过
UPDATE farmer_certification SET STATUS = 2, APPROVER_ID = ?, APPROVE_TIME = NOW() WHERE CERT_ID = ?;

-- 审批驳回
UPDATE farmer_certification SET STATUS = 0, APPROVER_ID = ?, APPROVE_TIME = NOW(), REJECT_REASON = ? WHERE CERT_ID = ?;
```


## 2. 土地信息管理模块

### 2.1 土地信息CRUD功能

#### 接口设计
```restful
GET /api/lands?page=1&size=10&keyword=   # 土地列表查询
GET /api/lands/{landId}                  # 土地详情
POST /api/lands                         # 新增土地
PUT /api/lands/{landId}                 # 更新土地信息
DELETE /api/lands/{landId}              # 删除土地
```

#### 开发要点
- 权限控制：管理员可操作所有土地，农民只能操作关联土地
- 多条件模糊查询（地块名称、行政区划）
- 分页查询优化
- 经纬度坐标验证
- 面积数值验证
- 关联农民用户验证（必须是已认证农民）

#### 数据库操作
```sql
-- 土地列表查询（管理员）
SELECT * FROM land_info 
WHERE (? IS NULL OR LAND_NAME LIKE CONCAT('%', ?, '%'))
AND (? IS NULL OR AD_CODE = ?)
ORDER BY CREATE_TIME DESC 
LIMIT ? OFFSET ?;

-- 土地列表查询（农民用户）
SELECT * FROM land_info 
WHERE FARMER_USER_ID = ?
AND (? IS NULL OR LAND_NAME LIKE CONCAT('%', ?, '%'))
ORDER BY CREATE_TIME DESC 
LIMIT ? OFFSET ?;

-- 新增土地
INSERT INTO land_info (LAND_NAME, OWNER_TYPE, AD_CODE, DETAIL_ADDRESS, AREA_SIZE, LAND_TYPE, CURRENT_STATUS, LATITUDE, LONGITUDE, FARMER_USER_ID, CREATE_BY, CREATE_TIME, UPDATE_TIME) 
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, NOW(), NOW());
```

## 4. 性能优化建议

### 4.1 数据库优化

- 分页查询使用游标分页避免深度分页问题
- 大字段（如文件路径）单独处理

### 4.2 缓存策略
