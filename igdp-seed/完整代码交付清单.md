## 六、快速开始

### 1. 执行数据库脚本

```bash
cd igdp-seed/src/main/resources/sql
mysql -u root -p your_database < seed_data_collection.sql
```

### 2. 启动应用

确保 igdp-seed 模块已在 igdp-admin 的 pom.xml 中引入,然后启动:

```bash
cd igdp-admin
mvn spring-boot:run
```

或直接运行主类: `com.inspur.IgdpApplication`

### 3. 测试接口

使用 Postman 或其他工具测试,例如:

**查询试验基础数据列表**:
```
POST http://localhost:8080/seed/trial/base/list
Content-Type: application/json

{
  "cropType": "小麦"
}
```

**新增农民地块数据**:
```
POST http://localhost:8080/seed/farmer/plot
Content-Type: application/json

{
  "farmerName": "张三",
  "gender": "男",
  "youthCategory": "青年",
  "cooperativeMembership": "是",
  "plotSizeM2": 1000.5,
  "contactPhone": "13800138000"
}
```

## 七、代码特点

### 1. 统一的分层架构

```
Controller (控制器层)
    ↓
Service (业务逻辑层)
    ↓
Mapper (数据访问层)
    ↓
Database (数据库)
```

### 2. 标准的CRUD实现

- **C**reate: `insertXxxData(DTO)` - 新增数据
- **R**ead: `selectXxxDataList(DTO)` / `selectXxxDataById(id)` - 查询
- **U**pdate: `updateXxxData(DTO)` - 修改数据
- **D**elete: `deleteXxxDataByIds(ids[])` - 逻辑删除

### 3. 使用 MyBatis Plus 简化开发

- 继承 `BaseMapper<T>` 获得基础CRUD
- 使用 `QueryWrapper` 构建查询条件
- 自动处理逻辑删除

### 4. 使用 Hutool 工具库

- `BeanUtil.copyProperties()` - 对象属性复制
- `StrUtil.isNotBlank()` - 字符串判空

### 5. 统一的响应格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

## 八、注意事项

### 1. 数据校验

前端需要根据API文档中的必填字段进行校验,后端建议添加 JSR-303 验证注解。

### 2. 文件上传

照片证据 (photoEvidence) 和实验室报告文件 (labReportFile) 需要集成文件上传功能,可使用 igdp-doc 模块的 MinIO。

### 3. JSON字段

`diseaseScore` 和 `stressIndicators` 字段存储JSON格式数据,前后端需要约定JSON结构。

### 4. 日期格式

统一使用:
- 日期: `yyyy-MM-dd`
- 日期时间: `yyyy-MM-dd HH:mm:ss`

### 5. GPS位置格式

建议格式: `"经度,纬度"` (例如: `"114.502,38.045"`)
