# 育种模块接口文档

## 一、Breeder Seed 生产数据采集相关接口

### 1. 生产数据列表查询接口

#### 接口说明
分页查询Breeder Seed生产数据列表，支持多条件筛选。

#### 请求信息
- **接口地址**: `/seed/breed/produce/list`
- **请求方式**: `GET`
- **接口描述**: 获取生产数据列表

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页数量，默认10 |
| breedSeedProduceBatchId | String | 否 | 种子生产批次ID |
| varietyId | String | 否 | 品种ID（关联品种发布表） |
| startTime | Date | 否 | 查询起始时间(格式: yyyy-MM-dd) |
| endTime | Date | 否 | 查询结束时间(格式: yyyy-MM-dd) |

#### 请求示例

```bash
GET /seed/breed/produce/list?pageNum=1&pageSize=10&varietyId=VAR123&startTime=2025-11-01&endTime=2025-11-30
```

#### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码(200-成功) |
| msg | String | 提示信息 |
| total | Long | 总记录数 |
| rows | Array | 生产数据列表 |

##### BreedSeedProduceVO 对象结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| breedSeedProduceBatchId | String | 种子生产批次ID |
| breedBatchId | String | 育种批次ID |
| varietyId | String | 品种ID |
| varietyName | String | 品种名称 |
| cropType | String | 作物类型 |
| time | String | 生产时间 |
| landId | String | 地块ID |
| landName | String | 地块名称 |
| inputSeedQuantity | BigDecimal | 投入种子数量 |
| produceSeedQuantrity | BigDecimal | 产出种子数量 |
| operatorId | String | 操作人ID |
| operatorName | String | 操作人姓名 |
| produceStatus | String | 生产状态 |
| createTime | String | 创建时间 |
| updateTime | String | 更新时间 |

#### 响应示例

```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 100,
  "rows": [
    {
      "breedSeedProduceBatchId": "UUID123",
      "breedBatchId": "BATCH123",
      "varietyId": "VAR123",
      "varietyName": "小麦品种A",
      "cropType": "小麦",
      "time": "2025-11-28 10:00:00",
      "landId": "LAND123",
      "landName": "地块一",
      "inputSeedQuantity": 100.00,
      "produceSeedQuantrity": 150.00,
      "operatorId": "USER123",
      "operatorName": "张三",
      "produceStatus": "FINISHED",
      "createTime": "2025-11-28 10:30:00",
      "updateTime": "2025-11-28 10:30:00"
```

- **请求方式**: `POST`
- **接口描述**: 新增分发数据，自动创建OSE接收确认记录

#### 请求参数

| 参数名 | 类型 | 必填 | 验证规则 |

## 附录

### 枚举值说明

#### 生产状态 (produceStatus)
| 值 | 说明 |
|----|------|
| FINISHED | 已完成 |

#### OSE状态 (oseStatus)
| 值 | 说明 |
|----|------|
| ENABLED | 启用 |
| DISABLED | 禁用 |

#### 接收状态 (receiveStatus)
| 值 | 说明 |
|----|------|
| PENDING | 待确认 |
| CONFIRMED | 已确认 |

### 业务流程说明

#### 育种家种子生产到分发流程
1. 育种家记录种子生产数据 → 生产状态: FINISHED
2. 育种家分发种子给OSE → 分发状态: 已分发
3. 系统自动创建OSE接收确认记录 → 接收状态: PENDING
4. OSE确认接收种子 → 接收状态: CONFIRMED

#### 数据自动带出规则
- **生产数据**: 自动从品种发布表带出品种名称、作物类型；从地块表带出地块名称；从用户表带出操作人姓名
- **分发数据**: 自动从OSE表带出OSE名称；从生产表带出品种名称、作物类型
- **OSE信息**: 自动从行政区划表带出行政区划名称

### 数据验证规则

1. **生产数据新增**:
   - 产出种子数量必须大于等于投入种子数量
   - 自动生成UUID作为批次ID
   - 自动设置生产状态为FINISHED

2. **分发数据新增**:
   - 分发数量不能超过生产批次剩余可分发量
   - 自动计算明细总数量
   - 自动创建OSE接收确认记录(状态为PENDING)

3. **OSE信息新增**:
   - OSE编码必须唯一
   - OSE名称必须唯一
   - 联系电话必须唯一，格式为251开头的12位数字
   - 默认状态为ENABLED

4. **接收确认**:
   - 只能确认状态为PENDING的记录
   - 确认后状态变更为CONFIRMED，不可重复确认

### 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 500 | 业务异常(详见msg字段) |

### 常见业务异常

- "产出种子数量必须大于等于投入种子数量"
- "分发数量超过生产批次剩余可分发量"
- "OSE行政编码已存在"
- "OSE名称已存在"
- "联系电话已存在"
- "接收确认记录不存在"

### 注意事项

1. **时间格式**: 所有时间字段格式为 `yyyy-MM-dd HH:mm:ss`，查询时间格式为 `yyyy-MM-dd`
2. **分页参数**: 不传pageNum和pageSize时使用默认值(1, 10)
3. **UUID生成**: 系统自动生成批次ID和分发ID，无需手动传入
4. **数据级联**: 分发数据新增时自动创建OSE接收确认记录
5. **数量计算**: 生产批次剩余量 = 产出数量 - 已分发数量总和
6. **唯一性约束**: OSE编码、名称、联系电话必须唯一
7. **状态管理**: 接收确认状态一旦变为CONFIRMED，不可回退
