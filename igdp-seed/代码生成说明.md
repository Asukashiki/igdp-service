## 生成模式说明

所有Service和Controller均遵循统一的代码模式:

### Service接口方法:
- `selectXxxList(DTO)` - 查询列表
- `selectXxxById(String id)` - 查询详情
- `insertXxx(DTO)` - 新增
- `updateXxx(DTO)` - 修改
- `deleteXxxByIds(String[])` - 批量删除

### Controller接口:
- POST `/list` - 查询列表
- GET `/{id}` - 查询详情
- POST `` - 新增
- POST `/edit` - 修改
- POST `/delete` - 批量删除

## 使用说明

1. **引入依赖**: igdp-seed模块已在 `igdp-admin` 的pom.xml中引入
2. **配置扫描**: Mapper和组件扫描已通过 `@Mapper` 和 `@Service` 注解自动配置
3. **执行SQL**: 运行 `src/main/resources/sql/seed_data_collection.sql` 创建数据库表
4. **启动测试**: 启动 `IgdpApplication` 主类,访问对应接口进行测试

## 开发规范

遵循 `后端开发提示词.md` 中的规范:
- 使用 MyBatis Plus 的 QueryWrapper 构建查询条件
- ID字段使用 String 类型,UUID主键生成策略
- 只使用 GET 和 POST 方法
- 返回类型使用 AjaxResult
- 逻辑删除标志: del_flag (0正常, 2删除)
- 使用 Hutool 的 BeanUtil 进行对象转换
- 不使用 Swagger 注解
