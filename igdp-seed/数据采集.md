# 研究与开发

## 育种数据管理

### 试验基础数据采集

#### 功能描述

试验基础数据采集主要采集育种试验，包括试验批次ID、作物类型、研究中心ID、项目ID、子项目ID、主题领域ID、地区、区域、县、乡、农业生态区、全球定位系统、开始日期、活动代码、季节，确保育种数据标准化、规范化，为后续育种数据采集提供支撑。

#### 使用对象

种子机构

#### 业务逻辑

种子机构人员新增试验基础数据，录入试验地点、实验室、作物类型、品种名称、研究中心ID等核心信息，系统提供数据校验，校验不通过则提示具体错误；

#### 原型设计

- 试验基础数据采集列表页面：  
  顶部为查询区，包括试验ID、作物类型、品种名称、查询时间起止；

- 试验基础数据采集新增/查看页面：  
  包括试验基础数据信息、操作人信息。

#### 输入信息

| 输入项           | 类型   | 必填 | 验证规则                             |
|------------------|--------|------|--------------------------------------|
| TrialID          | 字符串 | -    | 系统自动生成                         |
| 作物类型         | 枚举   | 是   | 须与育种试验关联                     |
| 品种名称         | 字符串 | 是   | 须与育种试验关联                     |
| 研究中心ID       | 字符串 | 是   |                                      |
| 程序 ID          | 字符串 | 是   |                                      |
| 子程序 ID        | 字符串 | 是   |                                      |
| 主题研究领域ID   | 字符串 | 是   |                                      |
| Region           | 列表   | 是   |                                      |
| Zone             | 列表   | 是   |                                      |
| Woreda           | 列表   | 是   |                                      |
| Kebele           | 列表   | 是   |                                      |
| 农业生态区       | 枚举   |      |                                      |
| GPS位置          | GPS    | 是   | 支持自动获取，自动获取失败手动录入   |
| 开始日期         | 日期   | 是   |                                      |
| ActivityCode     | 字符串 | 否   |                                      |
| KPI_Code         | 字符串 | 否   |                                      |
| 季节             | 枚举   | 是   |                                      |

#### 输出信息

无。

#### 数据库设计

参照输入信息。
