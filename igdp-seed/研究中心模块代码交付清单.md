# 研究中心模块代码交付清单

## 模块概述
研究中心模块用于管理农业研究中的各个研究中心信息，包括位置、地理坐标、行政区域等基础信息。

## 数据库设计

### 表结构
- **表名**: `location_master`
- **描述**: 研究中心表
- **主键**: `location_id` (String, UUID)

### 字段说明
| 字段名 | 类型 | 长度 | 说明 |
|--------|------|------|------|
| location_id | varchar | 64 | 位置ID (主键) |
| location_name | varchar | 100 | 位置名称 |
| region | varchar | 100 | 地区 |
| zone | varchar | 100 | 区域 |
| woneda | varchar | 100 | 沃雷达（行政区域） |
| latitude | decimal | 10,2 | 纬度 |
| longitude | decimal | 10,2 | 经度 |
| create_by | varchar | 64 | 创建者 |
| create_time | datetime | - | 创建时间 |
| update_by | varchar | 64 | 更新者 |
| update_time | datetime | - | 更新时间 |
| remark | varchar | 500 | 备注 |

### 索引设计
- `idx_location_name`: 位置名称索引
- `idx_region`: 地区索引  
- `idx_zone`: 区域索引

## 接口功能清单

### 1. 分页查询研究中心
- **接口地址**: `/seed/locationMaster/page`
- **请求方式**: POST
- **功能**: 支持按条件分页查询研究中心信息
- **查询条件**: 位置ID、位置名称、地区、区域、沃雷达

### 2. 新增研究中心
- **接口地址**: `/seed/locationMaster/add`
- **请求方式**: POST
- **功能**: 新增研究中心信息
- **验证**: 位置名称必填，长度限制

### 3. 修改研究中心
- **接口地址**: `/seed/locationMaster/update`
- **请求方式**: POST
- **功能**: 修改研究中心信息
- **验证**: 位置ID必填

### 4. 删除研究中心
- **接口地址**: `/seed/locationMaster/delete`
- **请求方式**: GET
- **功能**: 删除指定研究中心
- **参数**: locationId

### 5. 获取研究中心详情
- **接口地址**: `/seed/locationMaster/detail`
- **请求方式**: GET
- **功能**: 获取指定研究中心详细信息
- **参数**: locationId

### 6. 查询研究中心列表
- **接口地址**: `/seed/locationMaster/list`
- **请求方式**: POST
- **功能**: 查询研究中心列表信息（不分页）
- **参数**: 位置ID、位置名称、地区、区域、沃雷达

## 技术规范遵循

### 1. 命名规范
- **类命名**: 大驼峰式命名法（如：LocationMaster）
- **方法命名**: 小驼峰式命名法（如：getLocationName）
- **数据库字段**: 下划线命名法（如：location_name）

### 2. 技术栈
- **框架**: Spring Boot
- **ORM**: MyBatis Plus
- **工具库**: Hutool
- **代码简化**: Lombok
- **主键生成**: UUID

### 3. 接口规范
- **分页查询**: 使用IPage对象
- **返回类型**: AjaxResult统一封装
- **请求方式**: 仅使用GET和POST
- **查询构建**: 使用QueryWrapper

### 4. 数据验证
- **必填验证**: 位置名称不能为空
- **长度验证**: 字符串字段长度限制
- **格式验证**: 经纬度使用BigDecimal类型
