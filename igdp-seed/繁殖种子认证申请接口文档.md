# 繁殖种子认证申请接口文档

## 接口概述

本文档描述繁殖种子认证申请模块的RESTful API接口,包括认证申请的增删改查等功能。

**基础路径**: `/seed/breeding/certification`

**返回格式**: 统一使用AjaxResult包装

---

## 1. 分页查询认证申请列表

### 1.1 接口信息

- **接口路径**: `/seed/breeding/certification/page`
- **请求方法**: POST
- **接口描述**: 分页查询繁殖种子认证申请列表,支持按申请单位、作物种类、品种名称、查询时间筛选

### 1.2 请求参数

**Query参数**:

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页数量 | 10 |

**Body参数** (BreedingSeedCertificationDTO):

```json
{
  "applyOrgName": "string",     // 申请机构名称(模糊查询)
  "cropType": "string",         // 作物类型
  "varietyName": "string",      // 品种名称(模糊查询)
  "recordDate": "2025-11-29"    // 备案日期
}
```

## 3. 获取认证申请详情

### 3.1 接口信息

- **接口路径**: `/seed/breeding/certification/detail/{dataId}`

| dataId | String | 是 | 数据ID |

## 8. 注意事项

1. **数据ID生成**: 所有表的主键ID使用UUID策略自动生成,前端不需要传递主键ID(新增时)
2. **逻辑删除**: 删除操作为逻辑删除,将`del_flag`字段设置为"2",不会物理删除数据
3. **关联数据**: 删除主表数据时,会自动删除关联的品种信息、技术性状、试验数据、监管信息
4. **事务处理**: 新增和修改操作都使用了事务,确保数据一致性
5. **文件上传**: 试验报告、照片、认证文件等字段存储的是文件路径,需先调用文件上传接口获取路径
6. **日期格式**: 日期字段使用"yyyy-MM-dd"格式,时间字段使用"yyyy-MM-dd HH:mm:ss"格式
7. **分页参数**: 分页查询默认pageNum=1, pageSize=10
8. **查询条件**: 机构名称和品种名称支持模糊查询

