# 出入库管理系统 - 接口设计文档和数据库建表语句

## 一、数据库建表语句

###仓库表
```sql
CREATE TABLE `inv_warehouse` (
	`warehouse_id` BIGINT(19) NOT NULL AUTO_INCREMENT COMMENT '仓库ID',
	`warehouse_code` VARCHAR(50) NOT NULL COMMENT '仓库编号' COLLATE 'utf8mb4_0900_ai_ci',
	`warehouse_name` VARCHAR(100) NOT NULL COMMENT '仓库名称' COLLATE 'utf8mb4_0900_ai_ci',
	`warehouse_type` VARCHAR(20) NOT NULL COMMENT '仓库类型：normal-普通仓库/cold-冷藏仓库/dangerous-危险品仓库' COLLATE 'utf8mb4_0900_ai_ci',
	`location` VARCHAR(255) NOT NULL COMMENT '仓库地址' COLLATE 'utf8mb4_0900_ai_ci',
	`capacity` DECIMAL(15,2) NOT NULL COMMENT '仓库容量',
	`used_capacity` DECIMAL(15,2) NULL DEFAULT '0.00' COMMENT '已用容量',
	`status` CHAR(1) NULL DEFAULT '1' COMMENT '状态：0-停用/1-启用' COLLATE 'utf8mb4_0900_ai_ci',
	`contact_person` VARCHAR(50) NULL DEFAULT NULL COMMENT '联系人' COLLATE 'utf8mb4_0900_ai_ci',
	`contact_phone` VARCHAR(20) NULL DEFAULT NULL COMMENT '联系电话' COLLATE 'utf8mb4_0900_ai_ci',
	`region` VARCHAR(100) NULL DEFAULT NULL COMMENT 'Region (行政区划一级)' COLLATE 'utf8mb4_0900_ai_ci',
	`zone` VARCHAR(100) NULL DEFAULT NULL COMMENT 'Zone (行政区划二级)' COLLATE 'utf8mb4_0900_ai_ci',
	`woreda` VARCHAR(100) NULL DEFAULT NULL COMMENT 'Woreda (行政区划三级)' COLLATE 'utf8mb4_0900_ai_ci',
	`organ_name` VARCHAR(100) NULL DEFAULT NULL COMMENT '仓库归属部门' COLLATE 'utf8mb4_0900_ai_ci',
	`organ_code` VARCHAR(100) NULL DEFAULT NULL COMMENT '部门编码' COLLATE 'utf8mb4_0900_ai_ci',
	`full_address` VARCHAR(500) NULL DEFAULT NULL COMMENT '完整地址' COLLATE 'utf8mb4_0900_ai_ci',
	`gps_latitude` DECIMAL(10,8) NULL DEFAULT NULL COMMENT 'GPS纬度',
	`gps_longitude` DECIMAL(11,8) NULL DEFAULT NULL COMMENT 'GPS经度',
	`warehouse_area` DECIMAL(10,2) NULL DEFAULT NULL COMMENT '仓库面积(平方米)',
	`site_certificate` VARCHAR(500) NULL DEFAULT NULL COMMENT '场地证明文件' COLLATE 'utf8mb4_0900_ai_ci',
	`remark` VARCHAR(255) NULL DEFAULT NULL COMMENT '备注' COLLATE 'utf8mb4_0900_ai_ci',
	`create_people` VARCHAR(50) NOT NULL COMMENT '创建人' COLLATE 'utf8mb4_0900_ai_ci',
	`create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
	`update_people` VARCHAR(50) NULL DEFAULT NULL COMMENT '修改人' COLLATE 'utf8mb4_0900_ai_ci',
	`update_time` DATETIME NULL DEFAULT NULL COMMENT '修改时间',
	`del_flag` CHAR(1) NULL DEFAULT '0' COMMENT '删除标志：0-正常/2-删除' COLLATE 'utf8mb4_0900_ai_ci',
	PRIMARY KEY (`warehouse_id`) USING BTREE,
	UNIQUE INDEX `uk_warehouse_code` (`warehouse_code`, `del_flag`) USING BTREE,
	INDEX `idx_warehouse_type` (`warehouse_type`) USING BTREE,
	INDEX `idx_status` (`status`) USING BTREE,
	INDEX `idx_del_flag` (`del_flag`) USING BTREE,
	INDEX `idx_warehouse_region` (`region`) USING BTREE,
	INDEX `idx_warehouse_zone` (`zone`) USING BTREE,
	INDEX `idx_warehouse_woreda` (`woreda`) USING BTREE
)
COMMENT='仓库表'
COLLATE='utf8mb4_0900_ai_ci'
ENGINE=InnoDB
AUTO_INCREMENT=9
;

```

###入库单表
```sql
CREATE TABLE inbound_order (
  id VARCHAR(64) PRIMARY KEY COMMENT '数据ID',
  inbound_order_id VARCHAR(64) NOT NULL UNIQUE COMMENT '入库单ID',
  inbound_batch_id VARCHAR(64) NOT NULL COMMENT '入库批次号',
  inbound_status VARCHAR(50) NOT NULL COMMENT '入库状态(pending/completed/cancelled)',
  inbound_type INT NOT NULL COMMENT '入库类型(0:生产入库 1:采购入库 2:调拨入库)',
  warehouse_id VARCHAR(64) NOT NULL COMMENT '入库仓库ID',
  related_order_no VARCHAR(255) COMMENT '关联单号',
  supplier_type VARCHAR(50) COMMENT '供应商类型',
  supplier_id VARCHAR(64) COMMENT '供应商ID',
  inbound_user VARCHAR(100) COMMENT '入库员',
  inbound_time DATETIME COMMENT '入库时间',
  total_quantity DECIMAL(18,2) NOT NULL COMMENT '入库总数量',
  apply_time DATETIME COMMENT '申请时间',
  audit_time DATETIME COMMENT '审核时间',
  audit_user VARCHAR(100) COMMENT '审核人',
  operator VARCHAR(50) NOT NULL COMMENT '经办人',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  remark VARCHAR(255) COMMENT '备注',
  INDEX idx_inbound_order_id (inbound_order_id),
  INDEX idx_inbound_batch_id (inbound_batch_id),
  INDEX idx_warehouse_id (warehouse_id),
  INDEX idx_inbound_status (inbound_status),
  INDEX idx_inbound_type (inbound_type),
  INDEX idx_supplier_id (supplier_id),
  INDEX idx_inbound_time (inbound_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='入库单表';
```

###库存表
```sql
CREATE TABLE stock (

  outbound_quantity DECIMAL(18,2) NOT NULL DEFAULT 0 COMMENT '出库数量',
  expiry_date DATE COMMENT '过期日期',
  qr_code VARCHAR(255) COMMENT '二维码',
  status VARCHAR(50) DEFAULT 'active' COMMENT '状态',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  UNIQUE KEY uk_warehouse_material_batch (warehouse_id, material_id, material_batch_id),
  INDEX idx_warehouse_id (warehouse_id),
  INDEX idx_material_id (material_id),
  INDEX idx_expiry_date (expiry_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='库存表';
```

```sql
  id VARCHAR(64) PRIMARY KEY COMMENT '拆分记录ID',
```

#### B.5 执行出库
```
PUT /api/outbound/orders/{outbound_order_id}/confirm
```

**请求参数：**
```json
{
  "outbound_time": "2025-12-03 17:32:18",
  "operator": "string"
}
```

**响应逻辑：**
- 校验库存充足性
- 校验批次有效性（检查过期日期）
- 如果单个批次库存不足，自动拆分至多个入库批次
- 记录每个批次的出库数量和剩余库存
- 更新库存

## 三、核心业务逻辑说明

### 3.1 入库流程
1. **创建入库单** → 系统自动生成入库单ID和批次号
2. **信息审核** → 上级审核投入品分发单信息
3. **执行入库**：
   - 检查仓库是否存在（无则提示配置）
   - 校验仓库容量
   - 校验投入品存在性
   - 自动生成二维码
   - 更新库存和库存日志
   - 更新入库单状态为"已入库"

### 3.2 出库流程
1. **创建出库单** → 系统自动生成出库单ID和批次号
2. **信息审核** → 上级审核出库信息
3. **执行出库**：
   - 校验库存充足性
   - 校验批次有效性（过期日期）
   - 按FIFO原则扣减库存（先进先出）
   - 如果单个批次库存不足，自动拆分至多个入库批次
   - 记录批次拆分明细
   - 更新库存和库存日志
   - 更新出库单状态为"已出库"

### 3.3 库存更新规则
- 每次入库/出库操作都触发库存变动
- 库存表记录：当前库存、入库累计、出库累计
- 库存日志表完整记录每笔变动
- 库存公式：当前库存 = 入库累计 - 出库累计

### 3.4 批次管理
- **批次号生成规则**：`BATCH-{物料ID}-{日期时间戳}-{序号}`
- **二维码内容**：包含物料信息、批次号、仓库ID、有效期等
- **批次追溯**：支持从出库单追溯到原入库批次

## 四、错误处理

```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

**常见错误码：**
- `400`: 请求参数错误
- `401`: 未授权
- `403`: 无权限
- `404`: 资源不存在
- `409`: 仓库不存在
- `410`: 仓库容量不足
- `411`: 库存不足
- `412`: 投入品不存在
- `413`: 批次过期
- `500`: 系统内部错误
