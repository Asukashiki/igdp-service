# 反馈模块接口文档

## 1. 查询反馈列表

### 接口说明
分页查询反馈列表，支持多条件筛选。

### 请求信息
- **接口地址**: `/feedback/list`
- **请求方式**: `GET`
- **接口描述**: 获取反馈列表，支持按类型、状态、优先级、时间范围等条件筛选

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页数量，默认10 |
| feedbackType | String | 否 | 反馈类型(0-投诉/1-建议/2-咨询/3-故障报告/4-其他) |
| status | String | 否 | 状态(0-待处理/1-处理中/2-已完成/3-已关闭) |
| priority | String | 否 | 优先级(0-低/1-中/2-高/3-紧急) |
| handlerId | String | 否 | 处理人ID |
| keyword | String | 否 | 关键词(搜索标题、内容、反馈编号) |
| startTime | String | 否 | 开始时间(格式: yyyy-MM-dd HH:mm:ss) |
| endTime | String | 否 | 结束时间(格式: yyyy-MM-dd HH:mm:ss) |

### 请求示例

```bash
GET /feedback/list?pageNum=1&pageSize=10&status=0&priority=2&keyword=系统问题
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码(200-成功) |
| msg | String | 提示信息 |
| total | Long | 总记录数 |
| rows | Array | 反馈列表 |

## 2. 获取反馈详情

### 接口说明
根据反馈ID获取反馈详情，包含所有回复记录。

### 请求信息
- **接口地址**: `/feedback/{feedbackId}`
- **请求方式**: `GET`
- **接口描述**: 获取单个反馈的完整信息，包括所有回复

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| feedbackId | Long | 是 | 反馈ID(路径参数) |

### 请求示例

```bash
GET /feedback/1
```

| 参数名 | 类型 | 说明 |

## 3. 提交反馈

### 接口说明
用户提交新的反馈信息。

### 请求信息
- **接口地址**: `/feedback`
- **请求方式**: `POST`
- **接口描述**: 提交反馈，系统自动生成反馈编号，默认状态为待处理

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| feedbackType | String | 是 | 反馈类型(0-投诉/1-建议/2-咨询/3-故障报告/4-其他) |
| title | String | 是 | 反馈标题(最大200字符) |
| content | String | 是 | 反馈内容 |
| inputName        | String | 投入品名称       |
| supplierName     | String | 供应商名称       |
| contactName | String | 否 | 联系人姓名(最大100字符) |
| contactPhone | String | 否 | 联系电话(最大20字符) |
| contactEmail | String | 否 | 联系邮箱(最大100字符) |
| priority | String | 否 | 优先级(0-低/1-中/2-高/3-紧急)，默认0 |
| remark | String | 否 | 备注(最大500字符) |

### 请求示例

```json
{
  "feedbackType": "3",
  "title": "系统登录异常",
  "content": "多次尝试登录失败，提示密码错误，已尝试重置密码但仍然无法登录",
  "inputName": "农药",
   "supplierName": " supplierName",
  "contactName": "张三",
  "contactPhone": "13800138000",
  "contactEmail": "zhangsan@example.com",
  "priority": "2",
  "remark": "紧急问题，影响业务"
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码(200-成功) |
| msg | String | 提示信息 |

### 响应示例

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

## 4. 修改反馈

### 接口说明
修改反馈信息，仅待处理状态可修改。

### 请求信息
- **接口地址**: `/feedback`
- **请求方式**: `PUT`
- **接口描述**: 更新反馈信息，仅支持待处理状态的反馈

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| feedbackId | Long | 是 | 反馈ID |
| feedbackType | String | 是 | 反馈类型 |
| title | String | 是 | 反馈标题 |
| content | String | 是 | 反馈内容 |
| attachments | String | 否 | 附件 |
| contactName | String | 否 | 联系人姓名 |
| contactPhone | String | 否 | 联系电话 |
| contactEmail | String | 否 | 联系邮箱 |
| priority | String | 否 | 优先级 |
| remark | String | 否 | 备注 |

### 请求示例

```json
{
  "feedbackId": 1,
  "feedbackType": "3",
  "title": "系统登录异常(已补充信息)",
  "content": "多次尝试登录失败，提示密码错误。补充信息：使用Chrome浏览器，版本120.0",
  "attachments": "screenshot1.png,log.txt,browser_info.txt",
  "contactName": "张三",
  "contactPhone": "13800138000",
  "priority": "3",
  "remark": "非常紧急"
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码(200-成功/500-失败) |
| msg | String | 提示信息 |

### 响应示例

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

**错误响应示例**:
```json
{
  "code": 500,
  "msg": "只能修改待处理状态的反馈"
}
```

## 12. 获取反馈统计数据

### 接口说明
获取反馈的统计信息，用于仪表盘展示。

### 请求信息
- **接口地址**: `/feedback/stats`
- **请求方式**: `GET`
- **接口描述**: 获取反馈总数、各状态数量、各类型数量、平均满意度等统计数据

### 请求参数

无

### 请求示例

```bash
GET /feedback/stats
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码(200-成功) |
| msg | String | 提示信息 |
| data | Object | FeedbackStatsVO对象 |

#### FeedbackStatsVO 对象结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| totalCount | Long | 反馈总数 |
| pendingCount | Long | 待处理数量 |
| processingCount | Long | 处理中数量 |
| completedCount | Long | 已完成数量 |
| closedCount | Long | 已关闭数量 |
| complaintCount | Long | 投诉数量 |
| suggestionCount | Long | 建议数量 |
| consultationCount | Long | 咨询数量 |
| bugReportCount | Long | 故障报告数量 |
| otherCount | Long | 其他类型数量 |
| avgSatisfaction | BigDecimal | 平均满意度(保留2位小数) |
| avgProcessingHours | BigDecimal | 平均处理时长(小时，保留2位小数) |

### 响应示例

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "totalCount": 156,
    "pendingCount": 12,
    "processingCount": 8,
    "completedCount": 128,
    "closedCount": 8,
    "complaintCount": 23,

    "consultationCount": 67,
    "bugReportCount": 18,
    "otherCount": 3,
    "avgSatisfaction": 4.35,
    "avgProcessingHours": 6.75

}
```

### 业务流程说明

#### 反馈处理流程
1. 用户提交反馈 → 状态: 待处理
2. 管理员分配处理人 → 状态: 处理中
3. 处理人员处理反馈 → 状态: 已完成/处理中
4. 用户评价反馈 → 记录满意度
5. 关闭反馈 → 状态: 已关闭

#### 状态转换规则
- 待处理 → 处理中: 分配处理人时自动转换
- 处理中 → 已完成: 处理人员标记完成
- 已完成 → 已关闭: 手动关闭
- 任意状态 → 已关闭: 可直接关闭

#### 权限说明
- **用户权限**: 提交、修改(待处理状态)、删除、回复、评价(已完成状态)
- **处理人员权限**: 分配、处理、回复、关闭
- **管理员权限**: 所有操作

### 注意事项

1. **附件处理**: 附件字段存储的是文件路径或URL，多个附件使用逗号分隔
2. **时间格式**: 所有时间字段格式为 `yyyy-MM-dd HH:mm:ss`
3. **分页参数**: 不传pageNum和pageSize时使用默认值(1, 10)
4. **状态限制**:
   - 只能修改待处理状态的反馈
   - 只能评价已完成状态的反馈
5. **自动编号**: 反馈编号格式为 `FB + YYYYMMDD + 3位序号`，如 FB20251127001
6. **用户信息**: 创建反馈时自动从SecurityContext获取用户信息
7. **逻辑删除**: 删除操作为逻辑删除，实际数据保留在数据库中
8. **级联删除**: 删除反馈时会级联删除所有相关回复
