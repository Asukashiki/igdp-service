# 投入品配额分配管理系统开发说明

## 项目概述
本项目实现了农业投入品配额分配管理系统的两个核心功能:
1. **州级投入品年度配额管理** (State Annual Quota Management)
2. **投入品配额逐级分配管理** (Quota Allocation Management)

## 技术栈
- Spring Boot
- MyBatis Plus
- Hutool
- Lombok
- MySQL

## 数据库设计

### 1. t_state_annual_quota (州级投入品年度配额表)
- quota_id: 配额唯一标识 (UUID)
- quota_name: 配额名称
- year: 配额年度
- category_id: 投入品类别ID
- total_quota: 年度总配额量
- operator_id: 录入操作员ID
- operator_division_id: 操作员所属州级区划ID
- modifier_id: 修改人ID
- modifier_division_id: 修改人所属区划ID
- operate_time: 操作时间
- create_time: 创建时间
- update_time: 更新时间

### 2. t_quota_allocation (投入品配额逐级分配表)
- allocation_id: 分配记录唯一标识 (UUID)
- allocation_name: 分配记录名称
- year: 分配年度
- category_id: 投入品类别ID
- from_division_id: 分配方区划ID
- from_division_level: 分配方层级 (1=州、2=区、3=镇、4=村)
- from_parent_division_id: 分配方父级区划ID
- to_division_id: 接收方区划ID
- to_farmer_id: 接收方农民ID
- allocated_quota: 单次分配量
- quota_id: 关联州级总配额ID
- total_received_quota: 分配方本级接收的总配额量
- total_allocated_quota: 分配方累计已分配量
- remaining_quota: 分配方剩余配额量
- allocation_status: 分配状态 (0=未分配、1=部分分配、2=已完成)
- operator_id: 分配操作员ID
- operator_division_id: 操作员所属区划ID
- modifier_id: 修改人ID
- modifier_division_id: 修改人所属区划ID
- operate_time: 操作时间
- progress_update_time: 进度更新时间
- create_time: 创建时间
- update_time: 更新时间

## API接口

### 州级投入品年度配额管理

#### 1. 新增州级年度配额
- **接口**: POST /api/quota/state-annual/add
- **功能**: 录入州级投入品年度配额

#### 2. 分页查询州级年度配额
- **接口**: GET /api/quota/state-annual/page
- **功能**: 分页查询州级配额列表

#### 3. 查询州级年度配额详情
- **接口**: GET /api/quota/state-annual/detail
- **功能**: 查询单条配额详情

#### 4. 修改州级年度配额
- **接口**: POST /api/quota/state-annual/update
- **功能**: 修改配额总量

#### 5. 删除州级年度配额
- **接口**: POST /api/quota/state-annual/delete
- **功能**: 删除配额记录(需验证未分配)

### 投入品配额逐级分配管理

#### 1. 新增配额分配记录
- **接口**: POST /api/quota/allocation/add
- **功能**: 创建配额分配记录

#### 2. 分页查询配额分配
- **接口**: GET /api/quota/allocation/page
- **功能**: 分页查询分配记录列表

#### 3. 查询配额分配详情
- **接口**: GET /api/quota/allocation/detail
- **功能**: 查询单条分配详情

#### 4. 修改配额分配记录
- **接口**: POST /api/quota/allocation/update
- **功能**: 修改分配量(需验证总量限制)

#### 5. 删除配额分配记录
- **接口**: POST /api/quota/allocation/delete
- **功能**: 删除分配记录(需验证下级未分配)

## 核心业务逻辑

### 1. 州级配额管理
- 支持按年度、投入品类别录入总配额
- 同一年度、同一类别、同一州只能录入一次配额
- 修改配额时自动记录修改人信息
- 删除配额前需验证是否已分配给下级

### 2. 配额逐级分配
- 支持"州-区-镇-村-农民"五级分配
- 分配量自动累计,剩余量自动计算
- 分配状态自动更新(未分配/部分分配/已完成)
- 修改分配量时验证不超过总接收量
- 删除分配前验证接收方是否已向下分配

## 命名规范

### 数据库命名
- 表名: 小写+下划线 (如: t_state_annual_quota)
- 字段名: 小写+下划线 (如: operator_division_id)

### Java命名
- 类名: 大驼峰 (如: StateAnnualQuota)
- 方法名: 小驼峰 (如: selectPageWithDetail)
- 变量名: 小驼峰 (如: quotaId)

确保在主模块 igdp-admin 中包含本模块依赖。

### 3. 启动应用
使用 com.inspur.IgdpApplication 作为启动类。

### 4. 测试接口
可使用 Postman 或其他工具测试各接口功能。

## 错误处理
- 所有异常信息使用英文
- 使用 AjaxResult 统一返回格式
- 业务异常抛出 RuntimeException 并返回友好提示

## 注意事项
1. ID字段使用String类型,主键策略为UUID
2. 金额字段使用BigDecimal,保留2位小数
3. 仅使用GET和POST方法,不使用PUT和DELETE
4. 分页默认大小10,最大50
5. 所有时间字段使用LocalDateTime类型
6. 使用QueryWrapper构建查询条件
7. 不使用Swagger注解
