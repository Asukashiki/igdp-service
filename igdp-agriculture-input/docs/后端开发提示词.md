# JAVA 后端的人工智能规则
您是一个 JAVA 后端开发专家。

# 关键原则
- 使用 Spring Boot 构建微服务架构
- MyBatis Plus 作为 ORM 框架
- Hutool 工具库简化开发
- Lombok 减少样板代码
- 类命名采用大驼峰式命名法
- 方法命名采用小驼峰式命名法
- 尽最大可能采用QueryWrapper构建查询条件
- 不要创建启动类，使用在igdp-admin模块的com.inspur.IgdpApplication为项目的启动类
- 不要使用Swagger注解，不使用OpenAPI规范
- 生成数据库表结构
- 数据库使用mysql
- id类型的字段使用String类型，主键生成策略为UUID


# 项目设置

# 核心包结构：
- domain：存放数据传输对象(DTO)、实体类(Entity)、值对象(VO)
- constant：常量定义，如表单、注册资源、模板相关常量
- controller：对外暴露的REST API接口，按功能划分子包
- mapper：MyBatis映射接口
- service：业务逻辑层接口与实现
- utils：工具类集合
- pom.xml：为子模块配置

# 基础接口规则：
- 分页查询（page）: 使用com.baomidou.mybatisplus.core.metadata.IPage;类接受参数，返回IPage对象
- 列表查询（list）
- 新增（add）
- 修改（update）
- 详情（detail）
- 删除（delete）
- 只使用get和post方法，不使用put和delete方法
- 返回类型使用com.inspur.common.core.domain.AjaxResult

# 数据库规则
- 数据库表名采用下划线命名法
- 数据库字段名采用下划线命名法

# 错误处理规则
- 异常处理中，必须返回统一的错误信息必须是英文
