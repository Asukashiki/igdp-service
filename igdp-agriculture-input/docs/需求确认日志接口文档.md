# 需求确认日志接口文档

## 1. 接口概述

本文档描述了需求确认日志功能的前端接口，包括查询列表、获取详情、根据发送方和接收方查询、新增和删除等操作。

## 2. 接口列表

| 接口路径 | 请求方法 | 功能描述 |
|---------|---------|--------|
| `/agriculture/demand/confirmation/list` | GET | 查询需求确认日志列表（分页） |
| `/agriculture/demand/confirmation/{id}` | GET | 获取需求确认日志详情 |
| `/agriculture/demand/confirmation/byActors` | GET | 根据发送方和接收方查询需求确认日志 |
| `/agriculture/demand/confirmation` | POST | 新增需求确认日志 |
| `/agriculture/demand/confirmation/{id}` | DELETE | 删除需求确认日志（单条） |
| `/agriculture/demand/confirmation/batch` | DELETE | 批量删除需求确认日志 |

## 3. 接口详情

### 3.1 查询需求确认日志列表（分页）

**接口路径**：`/agriculture/demand/confirmation/list`
**请求方法**：GET
**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| fromActor | String | 否 | 发送方 |
| toActor | String | 否 | 接收方 |
| referenceId | String | 否 | 关联需求记录ID |
| confirmationType | String | 否 | 确认类型（Receipt/Delivery） |
| page | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页大小，默认10 |

**返回格式**：
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "list": [
      {
        "confirmationId": "string",
        "fromActor": "string",
        "toActor": "string",
        "referenceId": "string",
        "confirmationType": "string",
        "confirmationTypeDesc": "string",
        "confirmedTime": "2024-01-01T12:00:00",
        "createPeople": "string",
        "createTime": "2024-01-01T12:00:00"
      }
    ],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

```json
  }
```
```json
}
```

### 3.4 新增需求确认日志

**接口路径**：`/agriculture/demand/confirmation`
**请求方法**：POST
**请求体**：
```json
{
  "fromActor": "string",
  "toActor": "string",
  "referenceId": "string",
  "confirmationType": "string",
  "confirmedTime": "2024-01-01T12:00:00"
}
```

**参数说明**：

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| fromActor | String | 是 | 发送方（DA/Coop/Union/District/Zone/Region） |
| toActor | String | 是 | 接收方 |
| referenceId | String | 是 | 关联需求记录ID |
| confirmationType | String | 是 | 确认类型（Receipt-接收确认/Delivery-发送确认） |
| confirmedTime | Date | 否 | 确认时间，默认当前时间 |

**返回格式**：
```json
{
  "code": 200,
  "msg": "Add successfully",
  "data": {
    "confirmationId": "string",
    "fromActor": "string",
    "toActor": "string",
    "referenceId": "string",
    "confirmationType": "string",
    "confirmedTime": "2024-01-01T12:00:00",
    "createPeople": "string",
    "createTime": "2024-01-01T12:00:00",
    "updatePeople": "string",
    "updateTime": "2024-01-01T12:00:00",
    "delFlag": "0"
  }
}
```

### 3.5 删除需求确认日志（单条）

**请求参数**：

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| id | String | 是 | 确认ID |

**返回格式**：
```json
{
  "code": 200,
  "msg": "Delete successfully",
  "data": null
}
```

### 3.6 批量删除需求确认日志

**接口路径**：`/agriculture/demand/confirmation/batch`
**请求方法**：DELETE
**请求体**：

**参数说明**：

| 参数名 | 类型 | 必填 | 描述 |
|-------|------|------|------|
| ids | Array<String> | 是 | 确认ID数组 |

**返回格式**：
```json
{
  "code": 200,
  "msg": "Batch delete successfully",
  "data": null
}
```

## 4. 数据结构说明

### 4.1 需求确认日志VO

| 字段名 | 类型 | 描述 |
|-------|------|------|
| confirmationId | String | 确认ID |
| fromActor | String | 发送方（DA/Coop/Union/District/Zone/Region） |
| toActor | String | 接收方 |
| referenceId | String | 关联需求记录ID |
| confirmationType | String | 确认类型（Receipt-接收确认/Delivery-发送确认） |
| confirmationTypeDesc | String | 确认类型描述（接收确认/发送确认） |
| confirmedTime | Date | 确认时间 |
| createPeople | String | 创建人 |
| createTime | Date | 创建时间 |

## 5. 错误码说明

| 错误码 | 描述 |
|-------|------|
| 200 | 成功 |
| 500 | 服务器内部错误 |
| 400 | 请求参数错误 |
